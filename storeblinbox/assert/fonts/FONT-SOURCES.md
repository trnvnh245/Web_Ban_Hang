# Local fonts — sources and licensing

These files were downloaded from the official Google Fonts repository and the exact Font Awesome Free 6.4.0 CDN already used by the site.

## Google Fonts (SIL Open Font License 1.1)

- Montserrat-Variable.ttf: https://raw.githubusercontent.com/google/fonts/main/ofl/montserrat/Montserrat%5Bwght%5D.ttf
- PlayfairDisplay-Variable.ttf: https://raw.githubusercontent.com/google/fonts/main/ofl/playfairdisplay/PlayfairDisplay%5Bwght%5D.ttf
- PlayfairDisplay-Italic-Variable.ttf: https://raw.githubusercontent.com/google/fonts/main/ofl/playfairdisplay/PlayfairDisplay-Italic%5Bwght%5D.ttf
- DancingScript-Variable.ttf: https://raw.githubusercontent.com/google/fonts/main/ofl/dancingscript/DancingScript%5Bwght%5D.ttf

Include all corresponding OFL-Montserrat.txt, OFL-PlayfairDisplay.txt and OFL-DancingScript.txt license files when redistributing.

These are full font files, not Latin-only subsets. All four have been checked against all 134 Vietnamese precomposed letters needed for Vietnamese text. Montserrat is the body/form font; it includes the dong currency symbol U+20AB. Playfair Display is for logo/display text.
